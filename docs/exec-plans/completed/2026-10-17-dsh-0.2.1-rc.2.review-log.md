  - A real mitigation (read-path confinement) is outside this plan's scope.
- **F2 (medium): ACCEPTED.** runtime.md's generic `--resume` paragraph now states the DeepSeek exception.
- **F3 (medium): ACCEPTED.** The spike test now asserts `DSH_ENABLED_ALLOWLIST == frozenset(spike)` and that an extra enabled id is refused.
